# ⚠ SYNTHETIC DEMO DATA — NOT EXPERIMENTAL DATA

Every CSV in this folder was **generated by a random simulation**
(`python -m src.make_demo_data`). Nothing here was measured on the prototype.

It exists only so that the software pipeline (parser, preprocessing,
training, evaluation, embedded export, tests) can be run and tested before
real data has been collected.

- File names start with `DEMO_SYNTHETIC_`.
- `plant_id` is `DEMO_plant_1`; `label_source` is `synthetic_demo`.
- Labels come from an **invented** rule (documented in `src/make_demo_data.py`)
  plus 5 % random label noise.
- The real-data pipeline refuses to load rows whose `plant_id` starts with `DEMO`.

Do not cite any metric computed on this data as a project result.
